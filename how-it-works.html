AI 결과는 어떻게 나오나요?

이 페이지는 테스트가 하는 일과 하지 않는 일을 설명합니다. 결과를 신뢰도 높은 사람 평가처럼 받아들이지 않도록, 점수와 한계를 함께 살펴보세요.

  2. 점수의 의미
  3. 한계와 편향
  4. 결과를 비교하는 방법

1. 이미지 분류 과정

사진 테스트는 사용자가 고른 이미지를 브라우저에서 받아, Teachable Machine으로 만든 이미지 모델에 전달합니다. 모델은 이미지에서 학습 중 접한 시각적 패턴을 바탕으로 각 클래스의 출력 점수를 계산하고, 이 사이트는 강아지와 고양이 클래스 점수를 비교해 결과를 표시합니다.

이 사이트에서 설명하는 “강아지상·고양이상”은 모델의 두 클래스 이름을 테스트용 표현으로 옮긴 것입니다. 사람의 얼굴에서 동물과 닮은 정도를 측정하는 전용 얼굴 분석 모델은 아닙니다. 사람 사진을 넣더라도 결과는 모델이 해당 입력을 두 클래스 중 하나로 분류한 출력일 뿐입니다.

처리 위치: 이미지 분류는 브라우저에서 실행합니다. 이미지 파일을 이 사이트 서버로 전송하거나 저장하는 기능은 없습니다. 모델 및 실행 라이브러리를 불러오기 위해 브라우저가 외부 서버에 연결하는 내용은 개인정보 처리 안내에서 확인할 수 있습니다.

2. 점수의 의미와 오해하기 쉬운 부분

결과 화면의 퍼센트는 모델 출력값을 보기 쉽게 표시한 것입니다. 가령 강아지 62%, 고양이 38%가 나오면 이 입력에 대해 모델이 강아지 클래스 쪽으로 더 높은 점수를 냈다는 뜻입니다. 이 값이 “사람이 62% 강아지처럼 보인다”거나, 모델이 62%의 사례에서 맞는다는 뜻은 아닙니다.

강아지상
62%
고양이상
38%

분류 모델의 출력 점수와 실제 정답률은 서로 다른 개념입니다. 별도의 대표성 있는 평가 데이터와 검증 절차가 없으면 점수만으로 정확도나 확신 정도를 판단할 수 없습니다. 이 사이트는 사람 얼굴에 대한 정확도를 주장하지 않습니다.

3. 한계와 편향

모델은 제작에 사용된 학습 예시와 설정의 영향을 받습니다. 학습 이미지가 특정 배경, 조명, 촬영 기기, 동물 품종 또는 구도에 치우쳤다면 그 특성에 반응할 수 있습니다. 사람 얼굴용으로 학습하거나 검증하지 않은 모델은 사람 사진에서 얼굴 특징 대신 배경·색상·구도 같은 단서를 사용할 수도 있습니다.

사진의 밝기, 거리, 회전, 가림, 해상도, 배경이 달라지면 점수가 변할 수 있습니다. 반려동물 사진 역시 모델이 학습한 조건 밖에 있을 수 있습니다. 따라서 점수는 재미를 위한 출력으로만 보고, 사람의 성격·외모·정체성에 대한 판단이나 채용·교육·금융 등 중요한 결정에 사용하지 마세요.

모델 파일과 이 웹페이지의 코드는 사용자가 제공한 모델을 연결한 개인 프로젝트입니다. 사이트 운영자가 모델 학습 데이터의 전체 구성이나 독립적인 성능 평가 결과를 확인했다고 주장하지 않습니다.

4. 사진을 바꾸어 비교할 때

사진마다 결과가 크게 달라지는지 알아보고 싶다면 한 번에 한 조건만 바꿔보세요. 같은 사람의 같은 장면에서 자른 범위만 바꾸거나, 같은 구도에서 조명만 다른 사진을 비교하는 식입니다. 배경·표정·각도·거리까지 모두 바꾸면 무엇이 점수 변화에 영향을 주었는지 구분하기 어렵습니다.

이런 비교는 모델의 동작을 직접 관찰하는 체험일 뿐, 통제된 과학 실험이나 모델 성능 평가가 아닙니다. 결과가 달라져도 어느 사진이 더 “진짜 모습”에 가깝다는 결론은 낼 수 없습니다. 더 나은 사진 준비 요령은 사진 선택 가이드를 참고하세요.
