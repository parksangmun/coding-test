테스트 사진, 어떻게 고르면 좋을까요?

사진 조건을 일정하게 맞추면 결과를 비교하기는 쉬워집니다. 다만 어떤 사진도 사람 얼굴에 대한 분류 정확도를 보장하지는 않습니다.

업로드 전 빠른 확인

✓ 이미지가 기기에서 정상적으로 열리는지 확인
✓ 얼굴이 너무 작거나 심하게 잘리지 않았는지 확인
✓ 얼굴을 가리는 물체와 강한 역광을 피하기
✓ 본인 또는 사용 허락을 받은 사진만 선택

사이트는 브라우저가 표시할 수 있는 이미지 파일을 받습니다. 화면에 JPG·PNG·WEBP를 권장하지만, 실제로 열 수 있는 형식과 크기는 브라우저와 기기에 따라 다를 수 있습니다. 업로드할 파일을 이 사이트에 보내는 서버 기능은 없습니다.

결과를 비교하고 싶다면

  1. 기준 사진 하나를 정합니다.
    얼굴과 배경이 모두 보이고, 흔들림이 적은 사진을 기준으로 삼으세요.
  2. 다른 조건은 그대로 둡니다.
    예를 들어 같은 사진에서 자른 범위만 바꿔 비교합니다. 조명·거리·표정·배경을 한 번에 모두 바꾸면 원인을 알기 어렵습니다.
  3. 두 결과를 기록해도 해석은 조심합니다.
    점수가 달라지는 것은 모델 출력이 입력 이미지에 민감하다는 관찰입니다. 어느 결과가 더 정확하거나 본질적인 모습이라는 뜻은 아닙니다.

테스트의 범위: 이런 비교는 사용자가 모델의 반응을 살펴보는 체험입니다. 대표성 있는 표본, 정답 라벨, 반복 검증을 갖춘 성능 평가가 아니므로 정확도나 공정성의 근거로 사용할 수 없습니다.

사진을 선택할 때의 개인정보

사진에는 얼굴뿐 아니라 주변 사람, 위치 정보, 집 안 풍경 등 원치 않는 정보가 포함될 수 있습니다. 꼭 필요한 사진만 선택하고, 타인의 사진은 동의를 먼저 받으세요. 어린이 사진은 보호자 허락 없이 공개하거나 공유하지 마세요.

이 사이트는 이미지를 브라우저 안에서 모델에 전달해 분석하며 서버에 저장하지 않습니다. 모델과 TensorFlow.js 라이브러리는 외부 서버에서 가져오므로 페이지를 열 때 브라우저가 해당 서비스에 접속합니다. 광고 제공 과정의 데이터 처리에 관한 설명은 개인정보 처리 안내에 정리했습니다.

작동하지 않을 때

분석 화면에서 오래 멈춰 있어요

모델과 브라우저 라이브러리가 외부에서 로드되어야 합니다. 인터넷 연결, 콘텐츠 차단 확장 프로그램, 브라우저 콘솔의 네트워크 오류를 확인하고 페이지를 새로고침해 보세요.

이미지를 선택했는데 결과가 없어요

다른 브라우저에서 이미지를 열어보거나, 기기에서 다시 저장한 JPG 또는 PNG 사본으로 시도하세요. 손상된 파일이나 브라우저가 지원하지 않는 이미지 형식일 수 있습니다.

분석은 됐지만 결과가 이상해요

모델은 정해진 두 클래스 중 하나를 고릅니다. 강아지나 고양이가 아닌 이미지에도 둘 중 하나의 점수를 낼 수 있으므로, 결과를 실제 분류로 단정하지 마세요. 더 자세한 내용은 모델과 점수 설명을 확인하세요.
