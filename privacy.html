개인정보 처리 안내

이 안내는 animal? 웹사이트가 사진과 방문 정보를 어떻게 다루는지 설명합니다.

최종 업데이트: 2026년 11월 19일

사진 분석

사용자가 선택한 이미지 파일은 이 사이트의 서버로 업로드하지 않습니다. 파일은 브라우저에서 미리보기와 모델 분석에 사용되며, 다시 테스트하거나 페이지를 떠날 때 미리보기용 브라우저 객체 URL을 해제합니다. 이 사이트는 사진이나 분석 결과를 서버에 저장하는 기능을 제공하지 않습니다.

분석을 위해 페이지는 Google Teachable Machine에서 모델 파일을, jsDelivr에서 TensorFlow.js 실행 라이브러리를 불러옵니다. 따라서 브라우저는 해당 서비스에 접속하여 파일을 요청합니다. 이들 서비스의 처리에는 각 제공자의 개인정보 처리방침과 설정이 적용됩니다.

광고 및 쿠키

이 사이트는 Google AdSense를 사용합니다. Google 및 광고 파트너는 광고 제공, 광고 개인화, 빈도 제한, 측정, 사기 방지를 위해 쿠키 또는 유사 기술을 사용할 수 있습니다. 실제 처리 방식은 방문자의 지역, 동의 설정, Google 계정과 브라우저 설정에 따라 다를 수 있습니다.

Google이 광고 관련 정보를 사용하는 방법은 Google 광고 개인정보 및 약관에서 확인하고, 내 광고 센터에서 광고 설정을 관리할 수 있습니다.

호스팅 및 접속 기록

사이트는 GitHub Pages를 통해 제공됩니다. 사이트 호스팅과 보안을 위해 GitHub가 방문 요청의 기술 정보를 처리할 수 있습니다. GitHub의 정보 처리에 대해서는 GitHub 개인정보 보호 정책을 확인해 주세요.

입력 폼과 개인 정보 제출

사이트에는 회원 가입, 댓글, 사진 업로드 서버 또는 문의 입력 폼이 없습니다. 문의를 위해 GitHub 이슈를 이용할 경우 GitHub 계정과 공개 이슈에 입력한 정보가 표시될 수 있습니다. 사진, 연락처 등 민감한 정보는 공개 이슈에 게시하지 마세요.

아동 및 타인의 사진

다른 사람의 이미지를 선택하거나 공유하기 전에 동의를 받으세요. 특히 아동 사진은 보호자의 허락을 받고 신중하게 다뤄 주세요. 테스트 결과는 사람을 평가하거나 차별하는 근거로 사용하지 마세요.

문의와 변경

이 안내 또는 사이트의 정보 처리에 대한 문의는 GitHub 이슈 페이지로 보내 주세요. 운영 기능이나 외부 제공자가 바뀌면 이 안내를 수정하고 업데이트 날짜를 갱신합니다.
